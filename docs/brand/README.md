# Una Voce Brand and Editorial Documentation

This directory contains the approved source of truth for Una Voce visual and editorial work.

## Current approved direction

The approved system is reverent, editorial, calm, contemplative, typography-first, and liturgical.

It should feel like a very good Catholic publication: part contemporary prayer book, part monastery noticeboard, and part high-end literary journal. The system should remain recognizably Una Voce without becoming a rigid template.

## Canonical documents

- [Editorial Standards](UNA_VOCE_EDITORIAL_STANDARDS.md) defines the project-wide writing voice, theological and pastoral guardrails, naming conventions, and punctuation rules.
- [Instagram Visual Guide](UNA_VOCE_INSTAGRAM_VISUAL_GUIDE.md) defines the approved social palette, typography, composition system, motifs, carousel pacing, launch sequence, and QA requirements.
- [Instagram Visual Direction Reference](UNA_VOCE_INSTAGRAM_VISUAL_DIRECTION_REFERENCE.png) is the approved visual reference board.

## Authority

Use these documents as the baseline for new public-facing copy, social artwork, campaign pages, and related design work.

When a new idea conflicts with this system, preserve the following unless a deliberate art-direction decision has been made:

1. Clear and pastoral language.
2. No em dashes in new or revised final copy.
3. Editorial typography and confident negative space.
4. Cohesion without a mandatory template.
5. Liturgical motifs that feel authored, not generic.
6. Legibility at phone size.
7. Prayer framed as invitation and participation, not performance or gamification.

## Change process

When the system evolves:

1. Update the relevant canonical guide first.
2. Update the studio implementation and examples.
3. Review both 4:5 and 1:1 crops.
4. Verify public copy against the editorial standards.
5. Record any new standing rule in these documents so the decision carries forward.
